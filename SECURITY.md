# Security Policy & Vulnerability Management

## Security Policy

SentiBot AI takes vulnerability security and PII privacy seriously. We implement strict multi-layered guardrails (`api/middleware/guardrails.py`), prompt injection filters, and PII masking.

## Reporting a Vulnerability

If you discover a security vulnerability in SentiBot AI, please email **aryansharmacse354@gmail.com** directly instead of opening a public issue.

### Response SLA
- **Initial Acknowledgment**: Within 24 hours.
- **Triage & Remediation Plan**: Within 72 hours.
- **Patch Release**: Within 7 days.
